# recon — code-anywhere 单一真相源

> 长期项目防失忆机制。新 session 第一件事读 PROGRESS.md，开口先复述当前分支。

## 结构

- `PROGRESS.md` — **唯一活的状态**：当前位置、作战地图、决策日志、资产索引
- `wiki/` — 稳定的领域/协议/架构知识（按主题拆文件，目前为空）

## 更新原则（硬协约）

- 分支出结论 → **立即** 标 🟢 + 写资产路径 + 一句话结论
- 分支证明走不通 → **立即** 标 🔴 + 废除原因
- 用户做决策 → **立即** 写决策日志（带日期）
- 新分支冒出 → **立即** 加节点

完整规范见 `~/.claude/CLAUDE.md`「项目记忆体系」节。

## 与其他文档的关系

- `docs/plans/*.md` — 2026-03 设计阶段产物（implementation-plan / research-report 等）。保留供查阅，但**不再回写进度**
- `CLAUDE.md`（项目根，若存在）— 项目协约，引用本 recon 作为单一真相源
